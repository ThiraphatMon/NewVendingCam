## ที่มา

ที่ตู้จริง: มีออเดอร์แต่ของไม่ตก → คนยืนหน้าตู้ → แสง/เงาเปลี่ยนใน ROI → ระบบยืนยันว่ามีของ (false positive)
วัดจากคลิปจริง `person_shadow.mp4` พบว่าการเปลี่ยนใน ROI มี 3 แบบปนกัน: ภาพสว่างขึ้นทั้งกรอบ (ค่าเฉลี่ย V 142 → 165 ค้าง), แสงสะท้อนบนพรม/แถบเทาด้านข้างเปลี่ยนรูป, และเงามืดเป็นช่วง ๆ

ทดลองนอกโปรแกรม (สคริปต์แยก, เทียบกับเฟรมแรก, ก้อน ≥150 px นิ่ง 13 เฟรม):

| วิธี | คลิปเงา: ยืนยันผิด | คลิปของ `small1pick_big1pick.mp4` |
|---|---|---|
| ไม่กรอง (ปัจจุบัน) | 4 | เจอ 2/2 (11.3s, 27.5s) |
| Hue consistency | 5 | เจอ 2/2 |
| MOG2 detectShadows | 3 และกลืนของนิ่งเป็นพื้นหลัง (เห็นของแค่ ~5%) | เจอ 2/2 |
| **Texture (local NCC)** | **1** (ก้อนเล็ก 256 px) | **เจอ 2/2 เวลาเท่าเดิม** |

หลักการ: แสง/เงา/การปรับแสงของกล้อง เปลี่ยนแค่ความสว่าง แต่ลวดลายพื้นผิวเหมือนเดิม — ของที่ตกลงมาทับลวดลาย
จุดที่ลวดลายระหว่าง "พื้นหลังของรอบ" กับ "เฟรมปัจจุบัน" ยังสัมพันธ์กันสูง = แค่แสง → ตัดออกจาก foreground mask

## S22 — texture shadow filter (เปิดเป็นค่าเริ่มต้น)

### config (เพิ่มใน config.py + .envexample + HANDOVER)
| ค่า | default | ความหมาย |
|---|---|---|
| `SHADOW_FILTER` | **`texture`** | `texture` = กรองแสง/เงา · `off` = แบบเดิม (ไว้เทียบ/ย้อนกลับ) |
| `SHADOW_NCC_WIN` | 7 | ขนาดหน้าต่าง (px, คี่) |
| `SHADOW_NCC_THR` | 0.6 | NCC มากกว่านี้ = ลวดลายเดิม = แค่แสง/เงา |
| `SHADOW_FLAT_VAR` | 4.0 | ถ้า variance ในหน้าต่างของทั้งพื้นหลังและเฟรมปัจจุบัน < ค่านี้ (ไม่มีลวดลายทั้งคู่) ถือเป็นแค่แสง |

### อัลกอริทึม (อ้างอิงที่ทดลองแล้ว)
ทำเฉพาะใน bounding box ของ ROI, ภาพ grayscale float32, ใช้ box filter (`cv2.blur`) ขนาด WIN:
```
ma, mb = blur(bg), blur(cur)
va = blur(bg*bg) - ma*ma ;  vb = blur(cur*cur) - mb*mb ;  cab = blur(bg*cur) - ma*mb
ncc = cab / sqrt(max(va*vb, 1e-3))
light_only = (ncc > THR) | ((va < FLAT_VAR) & (vb < FLAT_VAR))
fgmask[light_only] = 0          # ก่อน morphology / contour / การคิดสัดส่วน env change
```
- `bg` = พื้นหลังเดียวกับที่ใช้คำนวณ diff อยู่แล้ว (พื้นหลังของรอบ / background ปัจจุบันของ detector) — ไม่สร้าง background ใหม่
- ใส่ในจุดเดียวที่สร้าง foreground mask (เช่น `core/detect.py`) ให้ทุกทางที่ใช้ mask ได้ผลเหมือนกัน (tracker, env change ratio, ฯลฯ)
- **ไม่แตะ**: clean_bg stillness (เทียบเฟรมต่อเฟรม), S3, STRICT_STABILITY, CAPTURE_HOLD_SEC, MIN_AREA, MAX_BLOB_ROI_RATIO
- log 1 บรรทัดตอน startup: `Shadow filter: texture (win=7, ncc>0.6, flat_var<4.0)` หรือ `off`

### คลิปใหม่
ผู้ใช้วาง 2 คลิปนี้ไว้ที่ **root ของโปรเจค** — ให้หาว่า `redis_e2e.py` อ่าน `big1_pickup_cutted.mp4` จากโฟลเดอร์ไหน แล้วย้ายคลิปใหม่ไปไว้ที่เดียวกัน (บอก path ในรายงาน) · ถ้าโฟลเดอร์นั้นอยู่ใน git ให้ตรวจ `.gitignore` ว่าไม่ commit ไฟล์ mp4 ขนาดใหญ่ (คลิปละ ~50 MB)
- `person_shadow.mp4` — คนยืนหน้าตู้ มีแต่เงา/แสง ไม่มีของ (1920x1080 ~29.8 fps ~24 s, บันทึกจาก PC กล้องตัวจริง)
- `small1pick_big1pick.mp4` — ขนมชิ้นเล็กตก ~10.7s ถึงพื้น ~11.0s → ลูกค้าดันฝาเข้า 14.9–16.7s หยิบออก → ขวดน้ำใสตก ~26.4s ถึงพื้น ~26.9s → ฝาเปิด 29.2–30.2s หยิบ → ว่าง 32.2s (1920x1080 ~19.9 fps ~38 s)
- ROI ของ 2 คลิปนี้ (พิกัด 1920x1080 — ครอบพรมฟ้า + แถบเทาสองข้าง ตามที่ผู้ใช้ตั้งบนเว็บ): สี่เหลี่ยมประมาณ `(264,414)–(1275,720)` สร้างเป็นไฟล์ ROI เฉพาะของคลิปใน fixtures ของเทสต์ (อย่าแก้ `data/roi_config*.json`) — ถ้าดูภาพแล้วกรอบเพี้ยนจากพรม ปรับให้ครอบพรม+แถบเทาและรายงานพิกัดที่ใช้

### ทดสอบเดิม
- pytest ทั้งหมด + redis_e2e เดิม 11 ข้อ **ที่ SHADOW_FILTER=texture และ off** × SEND_S0=0 (และ SEND_S0=1 อย่างน้อยรอบสุดท้าย) — ผลต้องไม่แย่ลงจากเดิม
- ถ้าข้อเดิมข้อไหนเปลี่ยนผลเมื่อเปิด texture → **หยุดรายงาน** (สาเหตุ + ภาพ mask) ห้ามปรับ threshold อื่นเพื่อให้ผ่าน
- pytest ใหม่ของ filter: เงา/สว่างขึ้นทั้งภาพบนพื้นมีลาย → mask ว่าง · วัตถุมีลาย/สีเรียบ (ขาว, ดำ) บนพื้นมีลาย → ยังอยู่ใน mask · `off` = mask เท่าเดิมทุกพิกเซล
